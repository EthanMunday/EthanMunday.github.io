Hey there! Technically, this is my first new page on this site. I felt that after I was done with university, I need to put my all into my projects and what comes next. My only gripe with that idea is that my portfolio didn't look the best and using Google Sites didn't give me too much to work with. Therefore, after learning about GitHub Pages. I decided to move my portfolio here.

There still was a slight problem. Although GitHub Pages allows me complete control over the look of my website, I'm not exactly well versed in both website creation and website design, or really any sophisticated visual design at all. With that in mind and by researching a bit more, searching around some sites, and randomly selecting a theme that I think works, I added the Minimal Mistakes Jekyll theme!

Using Visual Studio Code exclusively for the first time has been an interesting experience. Coming from Visual Studio, I recognise I make close to 0 use of the shortcuts, commands and tools available in here (Almost reminds me of using Blender after only using 3DSMax). That being said, I'm enjoying using this program. The file explorer is a lot more readable and responsive than the Visual Studio explorer and being able to just acquire any package I need or create new folders and files and start working on them helps improve productivity.

Using Jekyll and Minimal Mistakes was definitely the harder learning curve. I understand why Ruby is popular, having the same sort of package system using gems does help with finding what I need, even when I realistically have no idea what I'm doing. However, I do now know some basics to getting a local website running for testing purposes and how I can do a decent amount using this site.

I will (or have already) added pages covering some important things that have happened before since it's a lot easier to do so here.
